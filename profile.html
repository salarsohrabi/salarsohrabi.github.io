Engineering profile

Broad enough to see the system. Deep enough to debug the layer.

I work across the embedded stack: low-level MCU software, real-time behavior, Linux/QNX platform work, automotive middleware and services, integration, test automation and hardware/software debugging. Earlier product work adds PCB, FPGA/DSP, GNSS, industrial control, medical devices and power electronics.

The common thread is not a list of tools. It is solving systems problems that cross boundaries: a signal path that becomes a software problem, a timing problem that becomes an OS problem, or an integration failure that requires understanding both the physical interface and the software architecture.
